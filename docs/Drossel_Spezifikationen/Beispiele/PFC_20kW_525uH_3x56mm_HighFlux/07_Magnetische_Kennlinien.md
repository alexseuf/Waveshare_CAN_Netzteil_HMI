# 7 Magnetische Kennlinien

Die differentielle Induktivität ist für die Stromwelligkeit um den DC-Arbeitspunkt maßgebend. Die Sekanteninduktivität beschreibt die Flussverkettung bezogen auf den Strom.

Der AL-basierte Anfangswert von etwa 525 µH wird separat betrachtet, da der empirische Magnetics-B(H)-Fit im Grenzbereich $H\rightarrow0$ einen kleinen Offset besitzt.

Die endgültige $L(I)$-Kennlinie ist von 0 A bis mindestens 90 A am Muster zu messen.
