# 14 Prüf- und Abnahmekriterien

## 14.1 Prüfmatrix

| Prüfung | Bedingung | Kriterium | Umfang | Dokumentation |
|---|---|---|---|---|
| Sichtprüfung |  | keine Beschädigung, sichere Zugentlastung | 100 % | Prüfprotokoll |
| Windungszahl |  | Sollwert eingehalten | 100 % / prozesssicher | Prüfprotokoll |
| Anfangsinduktivität | Kleinsignal, definierte Frequenz | innerhalb Freigabeband |  | Messwert |
| $L(I)$-Kennlinie | bis mindestens Spitzenstrom | innerhalb Kennlinienband | Muster / Serie | Kurve |
| DC-Widerstand | 25 °C | innerhalb Toleranz |  | Messwert |
| Isolationsprüfung | gemäß Isolationskonzept | kein Durchschlag/Überschlag |  | Prüfprotokoll |
| Temperaturtest | Nennbetrieb stationär | Grenzwerte eingehalten | Muster | Temperaturkurve |
| Kurzzeitüberlast | spezifizierte Leistung und Zeit | keine bleibende Änderung | Muster | Vor-/Nachmessung |
| Vibrationsprüfung | projektspezifisch | keine mechanische Schädigung |  | Prüfbericht |

## 14.3 Freigabekriterien

Die Serienfreigabe erfolgt erst nach dokumentierter Übereinstimmung von Berechnung, Musteraufbau und Messung. Abweichungen sind zu bewerten und im Änderungsverlauf festzuhalten.
