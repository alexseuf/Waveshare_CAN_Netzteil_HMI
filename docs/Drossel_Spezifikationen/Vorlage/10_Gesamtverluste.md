# 11 Gesamtverluste

## 11.1 Verlustbilanz

```math
P_\mathrm{ges}=P_\mathrm{Cu}+P_\mathrm{Core}+P_\mathrm{Zusatz}
```

Zusatzverluste können Anschlussverluste, Streuflussverluste, Wirbelstromverluste in Haltern und Schirmteilen sowie weitere projektspezifische Beiträge umfassen.

| Verlustanteil | Nennbetrieb | Überlast | Einheit | Nachweis |
|---|---:|---:|---|---|
| DC-Kupferverluste |  |  | W |  |
| AC-Kupferzusatzverluste |  |  | W |  |
| Kernverluste |  |  | W |  |
| Anschlussverluste |  |  | W |  |
| sonstige Zusatzverluste |  |  | W |  |
| **Gesamtverlust** |  |  | W |  |
