## 8.2 Flussdichtehub

```math
\Delta B=\frac{1}{N A_e}\int u_L(t)\,\mathrm dt
```

Für eine vereinfachte Worst-Case-Abschätzung kann, sofern für die Topologie gültig, eine analytische Voltsekundenbeziehung verwendet werden. Die endgültige Verlustrechnung soll den tatsächlichen Spannungsverlauf aus Simulation oder Messung verwenden.
